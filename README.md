# 📄 Enhancv Resume Builder (Full-Stack MERN Application)

A modern, interactive, and customizable Resume Builder built with React, Tailwind CSS, Vite, Node.js, Express, and MongoDB.

---

## ✨ Features
- 🎨 **Visual Resume Canvas**: Real-time interactive resume layout customization.
- 🔄 **Custom Sections**: Add, edit, remove, reorder (move up/down), and switch columns.
- 🛠️ **Section Controls**: Header, Education, Experience, Skills, Projects, and Summary sections.
- 💾 **Dual Storage Support**: MongoDB API database integration with automatic LocalStorage fallback.
- 📥 **PDF & Print Ready**: Download high-quality resume PDFs directly from the browser.

---

## 🚀 Getting Started

### 1. Backend Setup
```bash
cd server
npm install
npm start
```
*(Runs on `http://localhost:5000`)*

### 2. Frontend Setup
```bash
cd client
npm install
npm run dev
```
*(Runs on `http://localhost:5173`)*

---

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, jsPDF, html2canvas
- **Backend**: Node.js, Express.js, Mongoose, Morgan, CORS
- **Database**: MongoDB / MongoDB Atlas
